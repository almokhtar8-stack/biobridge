# The BioBridge 2.2 student journey

BioBridge 2.2 is a companion to the three Coursera courses. It no longer competes with them. A confused student
should be able to find the exact topic, understand it with one quick visual, practice if it helps, and go back to
Coursera, usually in 2 to 4 minutes.

## The default path: Quick Companion

1. **Open BioBridge.** The home page asks one question: *Which course and topic are you studying right now?*
   It shows the three courses (IBM Linux, Rice Python, KAUST Bioinformatics) and a search box.
2. **Find the topic.** Either pick the course, then the module, then the topic whose "Helps with" line names the
   lecture you just watched; or type a word such as `grep`, `cd`, `data frame` or `t-test` into the search box.
   Topic titles follow the public course outlines (checked 8 November 2026); BioBridge does not reproduce lecture
   content, timestamps, slides, quizzes or assignments.
3. **Understand it (2 to 4 minutes).** Every topic page has the same short shape:
   - **In short**: a plain-English explanation, then **Why you need it** in one or two sentences.
   - **See it**: an original, step-by-step visual. Press Next to move one caption at a time; a text version lists
     every step.
   - **A tiny example**: real code with its real output, verified by running it.
   - **Try it (optional)**: a terminal task in the browser, real Python in the browser, a step-through trace, an
     interactive lab, or an exercise with the downloadable practice files on your own computer. It opens only if
     you choose to start it.
   - **Common mistake**: what beginners often do, and what to do instead.
   - **Quick check (optional, not scored)**: one question with an explanation for every answer. Nothing is recorded.
4. **Go back to Coursera.** The page ends with a "Back to Coursera" button, links to the previous and next topic,
   and, if you want more, links to the full BioBridge lessons.

BioBridge remembers which topics you opened, only to show a tick and a "Pick up where you left off" link. Nothing in
the Companion is graded, and it adds no tasks, quizzes or deadlines.

## Practice files

The **Files** tab offers the heat-shock practice project as one small ZIP (or file by file), with a preview and a
"what it contains, why it exists, how you use it" note for every file. Two routes are kept clearly apart:

- **In the browser:** the practice terminal already holds the same files in `~/project`. It cannot read files on
  your computer, including the ZIP you download.
- **On your own computer:** step-by-step instructions for macOS, Linux and Windows (WSL or Git Bash), plus RStudio
  and pandas snippets.

Nineteen tested commands show exactly what you should see; every output was checked in real Bash on the extracted
ZIP and in the browser terminal. Troubleshooting covers wrong folders, permissions, Windows line endings, macOS
differences and working-directory problems in R and Python. Five optional challenges have hints and answers.
All data are simulated for teaching; the gene names and the direction of the heat-shock response are real biology.

## Optional depth: Explore deeply

Everything from BioBridge 2.1 is still there and still optional, one tap away under **Explore**: the 60 lessons in
four foundations, 22 interactive labs and 14 terminal missions, the course map (lessons per Coursera module),
placement practice, the review queue, progress, the glossary, the notebook and the study plan. Saved progress from
earlier versions carries over unchanged.

## Workload

The Companion adds no required work. Each topic is written to a budget (about 150 to 300 words of reading plus one
visual and one small example) and the content checker estimates every one of the 79 topics at 2.1 to 3.7 minutes.
The try-it activity and the quick check are optional, and neither records a score, a review item or a session.
